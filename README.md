# AllUnitySitemap

Sitemap generator web app built on Replit: **React + TypeScript** client,
Node server with **Drizzle ORM**, Tailwind CSS.

## Structure

- `client/` — React UI (Vite, shadcn-style components)
- `server/` — Express API + Drizzle schema
- `shared/` — shared types/schemas

Runs via the Replit workflow (`.replit`) or standard `npm run dev`.
